# 知识点笔记索引

一个主题一个文件，编号只为排序，不代表学习顺序。

## 写笔记的规则（重要）

1. **不许抄。** 抄一遍教程等于没学。用自己的话写，写不出来就是没懂。
2. **每篇必须有"和前端对不上的地方"。** 类比帮你快速入门，但真正要学的恰好是类比失效的部分——那里才是新知识。
3. **写"为什么"不写"是什么"。** "@Transactional 加在方法上开启事务"是文档；"为什么 this.save() 会让它失效"才是笔记。
4. **短。** 一屏能读完。写不下的拆成两篇。
